# Back to the Future with JPMS - Checkpointed Demo

A Java 25 / Maven demo project for the conference talk **Back to the Future with JPMS: Modularizing Modern Java Applications**.

This Git repository is intentionally built as a sequence of tagged checkpoints. Start with `demo-00-classpath` and move forward during rehearsal.

Requirements: JDK 25 and Maven 3.9+.

```bash
./scripts/build.sh
./scripts/run-classpath.sh
```
